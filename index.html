LINK & ACTIVATE
اربط اللوحة بالموقع الأساسي

    
أربع خطوات تجعل كل ما سبق يعمل فعلًا على duck_math: نشر ملف الحارس، تفعيله في صفحة الموقع، نشر الإعدادات، ثم فحص الربط. الأزرار أدناه تنفّذها نيابة عنك.

  

  

    

      

        

      

      

        
ملف الحارس guard.js

        
هذا الملف يقرأ config.json عند كل فتح: يضع أيقونتك المرفوعة مكان القديمة، يبدّل اسم الموقع وأيقونة التبويب، يطبّق الألوان، ويحجب الموقع إن كان متوقّفًا أو داخل نافذة مجدولة.

        
<script src="guard.js"></script>

        

          
          
          
        

        
إن تعذّر قراءة الإعدادات يبقى الموقع يعمل. الحارس لا يكسر الموقع أبدًا عند انقطاع الشبكة أو خطأ في الملف.

      

    

    

      
فحص الربط

      

      
      
لم يُفحص بعد

      

      

        
        
      

      
الفحص يتم عبر واجهة GitHub باستخدام التوكن المحفوظ، فيقرأ ملفات المستودع الحقيقية ويؤكّد وجود الحارس وتفعيله. أكمل بيانات المستودع في قسم النشر أولًا.

      
بعد الربط

      
كل تعديل تنشره من هذه اللوحة يظهر على الموقع خلال دقيقة تقريبًا (مدّة نشر GitHub Pages). الحارس يعيد قراءة الإعدادات كل ٦٠ ثانية، فالإيقاف والعودة يعملان دون إعادة نشر.
